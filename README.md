# Jamf Resource Deleter

A Python package for safely managing and deleting unused resources from Jamf Pro. Built on top of the [JamfPy SDK](https://github.com/thejoeker12/jamfpy-python-sdk-jamfpro), this tool provides batch deletion capabilities with built-in safety features including dry-run mode, backup/restore functionality, and comprehensive logging.

## Features

- **Batch Resource Deletion**: Delete multiple Jamf Pro resources from JSON input files
- **Dry-Run Mode**: Preview deletion operations without making changes
- **Backup & Restore**: Automatically backup resource configurations before deletion and restore them if needed
- **Comprehensive Resource Support**: Handle various Jamf Pro resource types including:
  - Computers
  - Computer Groups (Smart & Static)
  - Configuration Profiles
  - Policies
  - Scripts
  - Packages
  - Computer Extension Attributes
  - Restricted Software
  - Mac Apps
- **Detailed Logging**: Track all operations with configurable logging
- **Extensible Architecture**: Easy to add support for additional resource types

## Quick Start

```python
from jamfpy import Tenant
from jamf_resource_deleter import JamfResourceDeleter
from pathlib import Path

# Initialize Jamf Pro connection
client = Tenant(
  fqdn = "https://YOUR-JAMF-SERVER.com",
  auth_method="oauth2",
  client_id="YOUR-CLIENT-ID",
  client_secret="YOUR-CLIENT-SECRET",
  token_exp_threshold_mins=1
)

# Create deleter instance
deleter = JamfResourceDeleter(
    jamfpy_client=client
)

# Perform a dry-run to preview deletions
result = deleter.delete_from_json(
    json_file_path=Path("unused_resources.json"),
    dry_run=True,
    export=True
)

# Execute actual deletions with backup
result = deleter.delete_from_json(
    json_file_path=Path("unused_resources.json"),
    dry_run=False,
    export=True
)

print(f"Processed: {result.total_processed}")
print(f"Successful: {result.successful}")
print(f"Failed: {result.failed}")
```

## Usage

### Preparing Input Files

The deleter expects JSON files with resource information, typically generated by tools like [Prune](https://github.com/BIG-RAT/Prune). The JSON structure should look like:

```json
{
  "unusedPolicies": [
    {
      "id": 123,
      "name": "Old Policy"
    }
  ],
  "unusedScripts": [
    {
      "id": 456,
      "name": "Deprecated Script"
    }
  ],
  "unusedComputerGroups": [
    {
      "id": 789,
      "name": "Unused Group"
    }
  ]
}
```

### Dry-Run Mode

Always test your deletions first using dry-run mode:

```python
result = deleter.delete_from_json(
    json_file_path=Path("unused_resources.json"),
    dry_run=True,
    export=True  # Still shows what would be backed up
)
```

This will log all operations without making any changes to your Jamf Pro instance.

### Deleting with Backups

Enable the `export` parameter to create backups before deletion:

```python
result = deleter.delete_from_json(
    json_file_path=Path("unused_resources.json"),
    dry_run=False,
    export=True
)

if result.backup_path:
    print(f"Backup saved to: {result.backup_path}")
```

**Note**: Backups are not available for:

- **Packages**: No API endpoint available for retrieving full package data
- **Computers**: Resources cannot be recreated via API (devices must be re-enrolled)
- **Mac Apps**: No API endpoint available for retrieving configuration

### Restoring from Backup

If you need to restore deleted resources:

```python
# List available backups
backups = deleter.list_backups()
print("Available backups:", backups)

# Restore from a specific backup (dry-run first)
restore_result = deleter.restore_from_backup(
    backup_filename="backup_11012026_143022.json",
    dry_run=True
)

# Execute the restore
restore_result = deleter.restore_from_backup(
    backup_filename="backup_11012026_143022.json",
    dry_run=False
)
```

### Single Resource Deletion

Delete individual resources programmatically:

```python
result = deleter.delete_resource(
    resource_type="unusedPolicies",
    resource_id=123,
    resource_name="Old Policy",
    export=True
)

if result.success:
    print(f"Successfully deleted {result.resource_name}")
else:
    print(f"Failed: {result.error_message}")
```

## Advanced Configuration

### Custom Backup Directory

```python
deleter = JamfResourceDeleter(
    jamfpy_client=client,
    backup_dir=Path("/custom/backup/location")
)
```

### Custom Resource Registry

Extend the deleter with custom resource handlers:

```python
from jamf_resource_deleter.resource_registry import ResourceRegistry
from jamf_resource_deleter.handlers import ResourceHandler

class CustomHandler(ResourceHandler):
    resource_name = "Custom Resource"

    def delete(self, resource_id: int):
        # Custom deletion logic
        pass

    def get(self, resource_id: int):
        # Custom retrieval logic
        pass

    def create(self, resource_config: dict):
        # Custom creation logic
        pass

# Register custom handler
registry = ResourceRegistry()
registry.register("customResourceType", CustomHandler)

deleter = JamfResourceDeleter(
    jamfpy_client=client,
    registry=registry
)
```

### Disable Automatic Logging Configuration

```python
deleter = JamfResourceDeleter(
    jamfpy_client=client,
    configure_logging=False  # Use your own logging setup
)
```

## Error Handling

The package provides detailed error information through the `OperationResult` and `BatchResult` objects:

```python
result = deleter.delete_from_json(
    json_file_path=Path("unused_resources.json"),
    dry_run=False,
    export=True
)

# Check overall results
if result.failed > 0:
    print(f"Warning: {result.failed} operations failed")

    # Examine individual failures
    for op in result.results:
        if not op.success:
            print(f"Failed to delete {op.resource_name} (ID: {op.resource_id})")
            print(f"Error: {op.error_message}")
```

## Integration with Prune

This tool is designed to work seamlessly with [Prune](https://github.com/BIG-RAT/Prune), a tool for identifying unused Jamf Pro resources:

1. Run Prune to generate the unused resources JSON file
2. Review the output to verify resources to delete
3. Use Jamf Resource Deleter to safely remove the resources

## Best Practices

1. **Always start with dry-run mode** to verify what will be deleted
2. **Enable backups** for resources that support it (`export=True`)
3. **Review backup files** before proceeding with large-scale deletions
4. **Test restores** in a non-production environment first
5. **Keep backup files** until you're certain resources won't need to be restored
6. **Monitor logs** during deletion operations for any errors
7. **Use version control** for your input JSON files

## Limitations

- Resource deletion is subject to JamfPy SDK endpoint availability
- Some resources (Packages, Mac Apps, Computers) have limited backup/restore support due to API limitations
- Deletion operations are permanent unless backups are enabled and available
- Computer resources cannot be recreated via API and require device re-enrollment
